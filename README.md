# Kano Run — AI Traffic Junction Turn, Next 18

## Actual behavior change
- Replaces the previous lane-change-only turn with a two-stage visual turn.
- AI vehicles curve toward the visible crossroad, rotate to a sustained 90-degree heading, and continue sideways along the crossroad.
- Branch movement keeps the vehicle at the junction's world depth while the player advances, instead of allowing the vehicle to drift straight through the junction.
- Vehicles leave through the existing traffic despawn path after the crossroad is behind the player or they travel beyond the visible branch.
- The same `visualOffsetX` used for rendering remains the value used by existing collision calculations.
- GLB traffic actors and mobile instanced traffic receive the same branch heading.
- Adds a regression test for branch entry, sustained heading, sideways progress, and collision-aligned lateral position.

## Verification
Run `node --test tests/*.test.mjs` from this package. These are focused module/integration-fixture tests, not the full game test suite. Browser gameplay has not been verified in this environment.

## Integration boundary
The existing `KanoRoadNavigationUpgrade.js` already imports `KanoTrafficJunctionTurnUpgrade.js`. Replace that existing module with the included version and keep the other files unchanged. This package does not modify protected files, `public/`, or model assets.

The turn uses the crossroad generated by the current navigation scene. It is a visual branch-turn behavior, not a surveyed Kano street network or a route to a named destination.
