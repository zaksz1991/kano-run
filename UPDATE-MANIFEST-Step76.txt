ROOT CAUSE ADDRESSED
- Four career UI modules were observing document.documentElement subtree changes and calling render whenever the career host existed. Their render functions modify DOM descendants, creating a self-triggered render/mutation loop. Their broad observers were removed; feature render functions, domain events and existing bounded visible-screen refreshes remain.
- The static Life & Career host was missing even though these modules expected it.
- The existing setting rows are moved into the new screen before main.js creates UI, not cloned, preserving the original IDs and change handlers.
