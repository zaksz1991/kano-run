Kano Run — Passenger Occupancy Upgrade

Replacement file:
renderer3d.js

What this adds:
- 1–3 visible passenger occupants inside the player keke.
- Seat-specific positioning for the three available passenger seats.
- Passenger visual variations for standard, student, worker, market, elder and hajiya types.
- Body, head, arms, legs and optional bag geometry.
- Boarding animation driven by game.js passenger.boardedFrame.
- Passenger settling/bobbing during driving.
- Passenger body movement during braking.
- Passenger exit animation when a used drop-off reaches the player.
- Driver remains the renderer's existing driver and steering system.
- game.js remains authoritative for passenger count, capacity, fares, destinations, pickup and drop-off state.

No game.js changes are required for this upgrade.
No CDN, external model, paid asset, or API is used.
