KANO RUN GAMEPLAY + 50 ROUTE UPGRADE

Replace these files in the repository with the same paths:

Keep the existing vendor/three.module.js and the existing js/main.js imports.

Route fidelity: the 50 entries use recognizable real Kano districts, corridors, markets, institutions, and road connections as route equivalents. This package does not claim surveyed GPS-accurate road geometry; it uses corridor-specific names, landmark sequences, environment types, and scenery variations within the current procedural renderer.

Gameplay changes include slower initial movement and acceleration, less frequent traffic/coins, fewer ambient traffic vehicles, closer but less frequent checkpoint timing, route-driven scenery offsets, and an assigned mission at run start.

Test after deployment: route selection, START ROUTE, left/right steering, one collision, coin pickup, checkpoint interaction, mission progress, and garage/driver selection. If the current UI module has a separate driver/garage scroll renderer, its source file was not part of the available current file set, so this pack does not replace that UI module.
