TASK 30 — TURN DISPATCH HELPER

Copy js/KanoTrafficTurnDispatch.js into the project's js/ directory.
Import it after KanoJunctionTurnRuntime.js in the existing activation bridge:
  import './KanoTrafficTurnDispatch.js';

This only installs validated dispatch helpers and an audit function. The game's
traffic controller still needs to call dispatchKanoTrafficTurn({ vehicle, start,
end, turn, junction, durationMs }) once when a vehicle enters a junction. The
start/end points must be actual scene-space coordinates. Do not call every frame.
No real junction coordinates are fabricated by this module.
