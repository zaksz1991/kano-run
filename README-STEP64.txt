FILES
- index.html: complete replacement based on current GitHub main, preserving the existing app sections, manifest link, Apple touch icon and four original module entrypoints; adds the Step 64 module.
- js/KanoNorthernDriverDigitalLife.js: pure state and rules for data bundles, daily online-life situations, reputation and delayed job outcomes.
- js/KanoNorthernDriverDigitalLifeUpgrade.js: runtime LIFE & CAREER panel. Uses existing storage.js wallet/persistence and waits for the existing life-career panel.
- tests/KanoNorthernDriverDigitalLife.test.mjs: unit tests.
- tests/KanoDigitalLifeIntegrationGuard.test.mjs: integration/preservation guards.

FEATURE
- Buy fictional mobile data bundles using the existing wallet.
- Use data for online market listings, job applications, verifying viral claims, handling discriminatory group chats, avoiding scams, helping local businesses and protecting relationship privacy.
- Every daily situation resolves at most once. It expires without an automatic wallet penalty when ignored.
- No instant income is awarded for advertising. Job applications return an interview/not-selected outcome after two simulated days, without auto-crediting wages.
- All online actions and bundle purchases are blocked during an active driving shift.
- Data and digital-reputation state save locally. The simulated phone never reads real messages, contacts, accounts or network data.

INSTALLATION
Extract into the existing project root (where index.html and package.json live). Replace index.html with the included complete current-main-based file and add the two js files at exactly the paths shown. Copy the included tests into the project's tests folder. Do not replace main.js, game.js, renderer3d.js, storage.js, the service worker, manifest, CSS or any 3D models.

All bundle prices, data usage, reputation changes and delayed job results are fictional gameplay values. Actual browser rendering and physical-phone performance have not been tested in this environment.
