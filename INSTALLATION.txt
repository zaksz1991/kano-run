WHAT THIS PACKAGE CHANGES
- Adds Safari-prefixed backdrop-filter and user-select declarations.
- Removes inline style attributes from index.html and moves those layout rules into css/styles.css.
- Changes the viewport to width=device-width, initial-scale=1.0, viewport-fit=cover (no maximum-scale or user-scalable restriction).
- Removes the theme-color metadata declaration that triggered the Firefox compatibility hint.
- Uses the local system font stack; no Google Fonts stylesheet or webfont requests are made from these replacement files. This also avoids the third-party Google Fonts Expires, X-Frame-Options and X-XSS-Protection responses shown by the audit.
- Adds X-Content-Type-Options, a minimal CSP frame-ancestors directive, and Referrer-Policy through Vercel headers.
- Overrides Vercel's default must-revalidate cache policy for HTML, the manifest, icons, CSS and brand files. The Vite-hashed /assets files keep immutable one-year caching.
- Adds a version query to the stylesheet link: ?v=20261009-02. Increment this token after future CSS changes if you want to use a new URL.

INSTALL
1. Unzip this package at the repository root, preserving the css/ subdirectory.
2. Replace the three files above completely.
3. Commit and push the changes to trigger Vercel deployment.
4. After deployment, hard-refresh the site and rerun the audit.

IMPORTANT LIMITATIONS
- This package was built against the supplied full stylesheet and the saved index.html source available in this conversation. The deployed site could differ from that saved HTML. Review the diff before committing if the repository's current index.html has newer DOM or game UI elements.
- Fixed-name brand assets are configured for revalidation (max-age=0), rather than one-year immutable caching, because their current URLs are not content-hashed. The audit may still recommend renaming/versioning those image URLs; changing their URLs without reviewing current JavaScript references could break them.
- CSS/HTML/JSON checks were run locally. No live browser or Vercel deployment test was possible in this environment.
